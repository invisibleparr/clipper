# clipper

trim, crop and shrink video clips — telegram style. a small desktop app
in go with [fyne](https://fyne.io), built around one question: which few
seconds do i want to keep?

## clankware
this frontend for ffmpeg was entirely made with ai, qwen3.8-flash-next to be specific
i did not write a single line myself
also this project uses [ffmpeg](https://ffmpeg.org/) for all the heavy lifting, so please support them.

## features

- trim bar with two handles; audio files show a loudness waveform behind them so you can aim at peaks
- preview playback with loop, scrubbing and sound (volume popup on the speaker button)
- rotate in quarter turns, rubber-band crop, resolution presets that never upscale
- hq toggle for visually-lossless encodes, mute to drop audio entirely
- live file-size estimate encoded with your exact settings
- export keeps the original audio codec when the container accepts it, otherwise re-encodes to aac

## requirements

- `ffmpeg` and `ffprobe` on your PATH (everything media shells out to)
- an audio device is optional; without one the app stays fully usable and silent

## run it

```
go build -o clipper .
./clipper video.mp4        # or drag a file onto the window
```

mp4, mov, mkv, avi, webm, m4v, 3gp — anything ffmpeg can read.

## packaging

metadata lives in `FyneApp.toml`, the icon is generated by `tools/mkicon`
(`go run ./tools/mkicon`). with the fyne cli installed:

```
fyne package -os linux     # tarball with binary, desktop entry and icon
fyne release -os linux     # distribution build
```

## development

```
go test -race .            # integration suite; needs ffmpeg
gofmt -l . && go vet ./... && staticcheck ./...
```

the in-app help (press **?**) is the source of truth for UI behavior.
